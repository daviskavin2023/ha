# 3038-网关-ha (Home Assistant 智能家居网关中心)

> 渔来喔智能家居体系核心网关。部署于 PVE 10 宿主机，通过 KVM 虚拟机运行 Home Assistant OS (HAOS)，实现对全屋开关、插座的集中管控、状态监控与高阶任务编排。

---

## 📌 项目定位

- **主控大脑**：Home Assistant 承担全屋逻辑控制、复杂任务编排、能源数据监控与跨协议桥接。
- **射频天线**：原**小米中枢网关**仅保留作为底层射频（Bluetooth Mesh / Zigbee）信号接收器，不参与任何上层自动化编排。
- **重点接管**：全屋智能开关（零火/单火、多键转无线）、智能计量插座（功率监测、电量统计）。

## 🚀 核心架构与部署参数

- **宿主环境**：PVE 10 宿主机 (`10.10.10.10`)
- **虚拟机类型**：KVM (HAOS 官方 qcow2 镜像)
- **VM 规格**：
  - VM ID: `138` (名称: `haos-138`)
  - 固定 IP: `10.10.10.38/24`
  - 默认网关: `10.10.10.15` (旁路由)
  - DNS 服务器: `10.10.10.15` (旁路由)
  - BIOS: `OVMF (UEFI)`
  - Machine: `q35`
  - CPU: 2 vCPU (Type: `host`)
  - 内存: 4GB
  - 存储: 32GB ~ 64GB SSD (VirtIO SCSI Single, 开启 Discard)
  - 扩展特性: 开启 QEMU Guest Agent
- **访问端口**：
  - HA 原生 Web: `http://10.10.10.38:8123`
  - 渔来喔映射代号: `3038`

详细规划、技术避坑指南与实施步骤请参阅：[PRD.md](./PRD.md)。
