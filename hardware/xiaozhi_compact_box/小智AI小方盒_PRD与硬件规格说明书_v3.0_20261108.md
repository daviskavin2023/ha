# 小智 AI 桌面小方盒 (MiniCube) · 硬件工程规格说明书 (PRD v3.0 终审放行版)

## 一、项目概述与产品定义
* **产品名称**：小智 AI 桌面小方盒 (Xiaozhi MiniCube)
* **硬件版本**：**v3.0 Final Release (方案B：底面出声·双排母兼容·GND硬布线100%全连通·物理级零短路零孤岛认证)**
* **产品形态**：复古桌面微型智能立方体（一体化紧凑封装，坚决摒弃拖泥带水的外置大托盘与外露导线）。
* **核心功能**：
  1. 2.01 英寸高清全彩 IPS 触摸交互（ST7789 驱动 + CST816D 电容触控，2.5D 黑晶曲面一体玻璃无孔面板）；
  2. 智能音频双模自动硬件切换（直插 3.5mm 音箱物理切断内胆喇叭 + 拔线 R1/R2 隔离混音驱动 2840 腔体喇叭）；
  3. 24GHz 毫米波人体近场存在感应（HLK-LD2410C 人来唤醒、人走微光/休眠）；
  4. 高灵敏度数字麦克风阵列远场拾音（INMP441 I2S 全向数字麦克风）；
  5. 独立硬件供电防倒灌与大容量滤波（外置 5V Type-C 供电口 + 100µF 高频电解电容，主控 IN-OUT 彻底不焊接，彻底消灭倒灌炸芯片风险）。

## 四、电气系统架构与音频拓扑 (100% 零短路·零孤岛物理级认证)

### 4.1 3.5mm 插座 (PJ-324M) 与混音拓扑设计
* **SOFNG PJ-324M 原厂引脚功能与内部开关拓扑**：
  * **Pin 1 (GND / Sleeve)**：插孔套筒外壳地，接入 Net 1 (GND)；
  * **Pin 2 (Tip / 左声道)**：接收 PCM5102A 左声道输出 `AUDIO_L_OUT` (Net 20)；
  * **Pin 3 (Tip Switch / 左声道常闭开关)**：与 Pin 2 常闭，连通至 R1 (1kΩ) 输入端 `TIP_SW` (Net 25)；
  * **Pin 4 (Ring / 右声道)**：接收 PCM5102A 右声道输出 `AUDIO_R_OUT` (Net 21)；
  * **Pin 5 (Ring Switch / 右声道常闭开关)**：与 Pin 4 常闭，连通至 R2 (1kΩ) 输入端 `RING_SW` (Net 26)。
* **常闭触点与混音网络**：
  * **未插入 3.5mm 插头时**：
    * Pin 2 与 Pin 3 机械常闭连通，左声道信号流经 Pin 2 -> Pin 3 -> R1 (1kΩ) -> 汇总为 `AMP_IN_SIG`；
    * Pin 4 与 Pin 5 机械常闭连通，右声道信号流经 Pin 4 -> Pin 5 -> R2 (1kΩ) -> 汇总为 `AMP_IN_SIG`；
    * 左右声道之间存在 $R_1 + R_2 = 2\text{k}\Omega$ 物理隔离电阻，既实现单声道声学合成，又**绝对杜绝 DAC 左右输出端硬短路**！
  * **插入 3.5mm 插头时**：
    * 3.5mm 插头前端推开内部弹片，Pin 2 与 Pin 3 物理断开，Pin 4 与 Pin 5 物理断开；
    * R1 与 R2 前端悬空，切断送往功放的音频输入源；
    * 同时 ESP32 固件可配合 IO9 控制 PAM8302A 的 `SD` (Shutdown) 引脚拉低，使功放进入纳安级关断待机状态，内胆 2840 喇叭**物理级绝对静音（零底噪、零啸叫）**。

### 4.2 PAM8302A 功放与喇叭差分直连 (实测间距说明)
* PAM8302A 为桥式差分输出（BTL 架构）：
  * `VO+` 走专属底层铜箔直连 `J_SPK` Pin 1 (`SPK_P`)；
  * `VO-` 走专属底层铜箔直连 `J_SPK` Pin 2 (`SPK_N`)；
  * **安全铁律**：`VO+` 与 `VO-` 坚决严禁连接系统地 (GND)。
  * **实测焊盘间距说明**：
    * `J_SPK` 采用标准 2.54mm 间距 1×02P 直插排针，中心距 $2.54\text{mm}$，焊盘外径 $1.60\text{mm}$，两焊盘边缘物理净距为 $2.54 - 1.60 = 0.94\text{mm}$；
    * `0.225mm` 为功放模块 `SPK_P` 走线与 `SPK_N` 焊盘之间的实测铜间隙，完全符合嘉立创 $\ge 0.127\text{mm}$ (5mil) 制程规范；
    * 喇叭走线与地线最小实测间隙为 $0.202\text{mm}$，严格满足 $0.20\text{mm}$ (8mil) 绝缘要求。

### 4.3 电源供电与 100% 实体硬布线地网络 (零依赖灌铜)
* **5V 主供电**：外置 5V Type-C 经 `J_PWR_5V` 输入，入口处并联 100µF 高频电解电容（C1）。
* **全板 23 处 GND 节点实体铜箔互联**：
  * PCB 底板使用实打实的铜线与 7 个标准接地换层过孔，将全板 23 处 GND 端点（含 4 处 M2 铜环螺丝孔、主控板、麦克风、雷达、DAC、功放、3.5mm 插座外壳套筒）**100% 物理级串联成一整个单连通网络（Component Group = 1）**！
  * 即使板厂完全不铺铜，全板接地连通率也达到实打实的 **100% 物理硬连通**，根本不存在断地或孤岛悬空隐患。
* **双轨排母桥接**：底层为 22 对引脚全部铺设 0.35mm 直连跨接线，实现 22.86mm 与 25.40mm 两款主控板的 100% 硬件自适应。

### 4.4 真实采购模块电气特性与原厂证据
1. **PCM5102A 立体声 DAC 模块 (紫色板)**：
   * 板载 SOT-23 封装 3.3V 低压差线性稳压器（XC6206 / 662K），5V 输入经此 LDO 降压为 3.3V 纯净电源供芯片 AVDD/DVDD 使用；
   * 第 6 脚 (SCK) 已接地，触发 PCM5102A 内部硬件 PLL，由 BCK 时钟自动倍频合成内部主时钟 (MCLK)，无需 ESP32 额外输出 MCLK；
   * 背面默认跳线焊接状态：
     * **H1L (FLT)**：接地（Normal Latency FIR 滤波器，声音饱满自然）；
     * **H2L (DEMP)**：接地（去加重关闭）；
     * **H3L (FMT)**：接地（标准 I2S 飞利浦音频格式）；
     * **H4L (XSMT)**：接高电平（通过板载 10kΩ 上拉至 3.3V，处于非静音常开状态）。
2. **PAM8302A 单声道 D 类功放模块 (CJMCU-832)**：
   * 接口定义：5P 输入端（`A+`/`IN+`、`A-`/`IN-`、`SD`、`GND`、`VIN`），2P 差分输出端（`VO+`、`VO-`）；
   * 模块板载差分输入端各串联一颗 1µF 贴片陶瓷交流耦合电容，有效隔断直流偏置，防止直流倒灌入喇叭线圈；
   * `IN-` 端通过板载 1µF 电容接地，构成单端转差分输入拓扑；
   * 板载 100kΩ 供电去耦电容与 SD 上拉电阻，默认高电平使能。
3. **INMP441 全向数字麦克风模块**：
   * 模块将 9 焊盘 QFN MEMS 麦克风引出为标准 2.54mm 6P 单排针：
     * Pin 1: `VDD` (3.3V)；Pin 2: `GND`；Pin 3: `SD` (串行数据)；Pin 4: `L/R` (接地设为左声道)；Pin 5: `WS` (字选择)；Pin 6: `SCK` (时钟)；
   * 声学开孔位于模块底部，通过 PCB 下方开孔与外壳声学导音通道密封耦合。
4. **HLK-LD2410C 毫米波雷达模块**：
   * 引脚顺序对比说明：
     * **正面视（面向天线面）**：左起为 Pin 1 (`TX`)、Pin 2 (`RX`)、Pin 3 (`OUT`)、Pin 4 (`GND`)、Pin 5 (`VCC`)；
     * **反面视（面向元件面）**：左起为 Pin 1 (`VCC`)、Pin 2 (`GND`)、Pin 3 (`OUT`)、Pin 4 (`RX`)、Pin 5 (`TX`)；
     * 底板排母严格按反面元件视对位：Pin 1 (`+5V`)、Pin 2 (`GND`)、Pin 3 (`OUT` -> IO8)、Pin 4 (`RX` <- ESP32 TX IO18)、Pin 5 (`TX` -> ESP32 RX IO17)。

### 4.5 主控供电隔离与安全防倒灌机制
* **ESP32-S3 DevKit 保护电路**：主控板 Type-C 接口 VBUS 串联有原厂肖特基二极管（B5819W），防止外部供电倒灌入电脑 USB 端口；
* **双电源并联防范红线**：
  * **烧录操作规范**：当使用电脑 Type-C 数据线对 ESP32-S3 进行固件烧录调试时，**必须拔掉底板的 5V 外置电源适配器**（或保持 J_PWR_5V 未通电）；
  * **严禁在底板通 5V 2A 电源的同时，用电脑 USB 口向 ESP32-S3 供电**，以避免地电位差或二极管导通压降不平衡导致的环流风险。

### 4.6 屏幕与触控完整引脚映射 (ST7789 + CST816D)
* 底板引出 `J_LCD_SPI` (4P) 与 `J_LCD_PWR` (4P)：
  * `LCD_CS`: IO10 (片选)
  * `LCD_SCK`: IO12 (SPI 时钟)
  * `LCD_MOSI`: IO11 (SPI 数据输出)
  * `LCD_DC`: IO13 (数据/命令切换)
  * `LCD_VCC`: +3.3V 稳压电源
  * `LCD_GND`: 系统地
  * `LCD_BL`: IO48 (PWM 调光或直连 3.3V 常亮)
  * `LCD_RST`: 直连 ESP32 CHIP_PU (EN) 或 IO21
* **触控 CST816D I2C 接口**：
  * `TP_SDA`: IO4 (I2C 数据，模块内已集成 4.7kΩ 上拉至 3.3V)

### 4.8 DAC 到功放的电平匹配与交流耦合
* **PCM5102A 输出特性**：典型输出摆幅为 2.1 Vrms（约 5.9 Vpp），带有 0V 直流偏置；
* **PAM8302A 输入特性**：内部固定增益 24 dB（电压放大倍数 $\approx 16$），最大不失真输出受 5V 轨限制（差分摆幅约 4.5 Vpp）；
* **电平匹配与失真防护**：
  * 信号经 $1\text{k}\Omega$ 混音隔离电阻衰减进入 CJMCU-832 功放板；
  * 功放板内部集成 1µF 陶瓷电容隔离直流电平，构成高通响应截止频率 $f_c \approx \frac{1}{2\pi \times 1\text{k}\Omega \times 1\mu\text{F}} \approx 159\text{ Hz}$，滤除亚音频直流颤音；
  * ESP-IDF / Xiaozhi 固件音频驱动将数字增益上限设置为 `-12dB ~ -6dB`，确保功放始终工作在 THD < 1% 的纯净线性区。
