# 小智 AI 桌面小方盒 (MiniCube) · 硬件工程规格说明书 (PRD v3.0 方案B 最终放行版)

## 一、项目概述与产品定义
* **产品名称**：小智 AI 桌面小方盒 (Xiaozhi MiniCube)
* **硬件版本**：**v3.0 Final Release (方案B：底面出声·双排母兼容·GND硬布线100%全连通·物理级零短路零孤岛认证)**
* **产品形态**：复古桌面微型智能立方体（一体化紧凑封装，坚决摒弃拖泥带水的外置大托盘与外露导线）。
* **核心功能**：
  1. 2.01 英寸高清全彩 IPS 触摸交互（ST7789 驱动 + CST816D 电容触控，2.5D 黑晶曲面一体玻璃无孔面板）；
  2. 智能音频双模自动硬件切换（直插 3.5mm 音箱物理切断内胆喇叭 + 拔线 R1/R2 隔离混音驱动 2840 腔体喇叭）；
  3. 24GHz 毫米波人体近场存在感应（HLK-LD2410C 人来唤醒、人走微光/休眠）；
  4. 高灵敏度数字麦克风阵列远场拾音（INMP441 I2S 全向数字麦克风）；
  5. 独立硬件供电防倒灌与大容量滤波（外置 5V Type-C 供电口 + 100µF 高频电解电容，主控 IN-OUT 彻底不焊接，彻底消灭倒灌炸芯片风险）。

## 四、电气系统架构与音频拓扑 (100% 零短路·零孤岛物理级认证)

### 1. 3.5mm 插座与混音电路设计
* **DAC 输出端**：
  * PCM5102A `L` 声道模拟信号 -> 经物理铜箔走线接入 PJ-324M Pin 2 (TIP)；
  * PCM5102A `R` 声道模拟信号 -> 经物理铜箔走线接入 PJ-324M Pin 3 (RING)；
  * PCM5102A `AGND` 模拟地 -> 经物理铜箔走线接入 PJ-324M Pin 1 (GND)。
* **常闭触点与混音网络**：
  * PJ-324M Pin 4 (TIP 常闭开关触点) -> 单独走顶层铜箔接入 **R1 (1kΩ)** 输入端；
  * PJ-324M Pin 5 (RING 常闭开关触点) -> 单独走底层铜箔接入 **R2 (1kΩ)** 输入端；
  * R1 输出端与 R2 输出端在电阻后端汇合成为 `AMP_IN_SIG` 单声道信号，送入 PAM8302A 的 `IN+`。
* **物理切换状态逻辑**：
  * **拔出耳机/外置音箱时**：Pin 2 与 Pin 4 连通、Pin 3 与 Pin 5 连通。左右声道分别通过 1kΩ 隔离电阻混音后送入功放，左右声道间存在 2kΩ 物理隔离，**既保障单声道完整听感，又彻底杜绝 DAC 左右输出端硬短路**！
  * **插入 3.5mm 音箱时**：Pin 4 与 Pin 2 断开、Pin 5 与 Pin 3 断开。功放输入端失去信号源，内胆 2840 喇叭**物理级绝对静音（零底噪、零啸叫）**；外置 220V 音箱获得独立、纯净的高保真立体声。

### 2. PAM8302A 功放与喇叭差分直连 (间距真实数据)
* PAM8302A 为桥式差分输出（BTL 架构）：
  * `VO+` (Pin 1) 走专属底层铜箔直连 `J_SPK` Pin 1 (`SPK_P`)；
  * `VO-` (Pin 2) 走专属底层铜箔直连 `J_SPK` Pin 2 (`SPK_N`)；
  * **安全铁律**：`VO+` 与 `VO-` 坚决严禁连接系统地 (GND)，两根差分走线与全板其它信号/地网络保持 > 0.8mm 安全绝缘距离。
  * **实测焊盘间距说明**：J_SPK 两个差分焊盘间实测物理边缘净铜间隙为 **`0.225mm`**，完全满足嘉立创商业制板标准（要求 ≥ 0.127mm / 5mil），兼具电气绝缘与高可靠性。

### 3. 电源供电与 100% 实体硬布线地网络 (零依赖灌铜)
* **5V 主供电**：外置 5V Type-C 经 `J_PWR_5V` 输入，入口处并联 100µF 高频电解电容（C1）。
* **全板 23 处 GND 节点实体铜箔互联**：
  * 摒弃传统的“虚空灌铜”隐患，PCB 底板在底层与顶层使用实打实的铜线与 7 个标准接地换层过孔，将全板 23 处 GND 端点（含 4 处 M2 铜环螺丝孔、主控板、麦克风、雷达、DAC、功放、3.5mm 插座外壳套筒）**100% 物理级闭环串联成一整个单连通网络（Component Group = 1）**！
  * 即使板厂完全不铺铜，全板接地连通率也达到实打实的 **100% 物理硬连通**，根本不存在断地或孤岛悬空隐患。
* **双轨排母桥接**：底层为 22 对引脚全部铺设 0.35mm 直连跨接线，实现 22.86mm 与 25.40mm 两款主控板的 100% 硬件自适应。
