# 单电源UART维护接线

目标：烧录/查看日志时，不把电脑USB的5V与底板外部5V硬并联。使用ESP32-S3 ROM支持的3.3V UART，电脑只连接外置USB转串口适配器，底板继续由一只外部5V电源供电。

## 线束

| USB转串口适配器端 | 底板端 | 说明 |
|---|---|---|
| TXD，必须3.3V逻辑 | J_ESP_R1.3 或R2.3，SPARE_RX | 适配器发送→主控接收；两套排母只选一套 |
| RXD，3.3V兼容输入 | J_ESP_R1.2 或R2.2，SPARE_TX | 主控发送→适配器接收 |
| GND | J_ESP_R1.1 或R2.1，GND | 公共信号参考地 |
| 5V/VCC/3V3供电输出 | **不接；线束不装这一芯** | 底板和主控不从适配器取电 |
| DTR/RTS | 不接 | 用主控已有BOOT/RESET按钮进入下载模式 |

电脑USB只插外置适配器，**不要同时将电脑USB线插入主控开发板的任一USB口**。外置适配器的“3.3V”跳帽有时只改变供电引脚，购买/使用前应明确TXD逻辑电平为3.3V。不能使用5V TTL或RS-232接口。

这是“没有USB VBUS供电导线的串口维护线束”，不是电气隔离器，也不声称支持任意双电源同时连接。不会私改未知主控USB桥或稳压器电路。线束接入后仍须确认主控板载串口桥是否影响外部UART；如通信失败，先核对该具体开发板原理图，不强行加压。

## 进入下载模式

底板保持正常外部供电。按住主控BOOT，按一下RESET/EN后释放，再释放BOOT。串口从115200开始识别芯片。此处仅提供接线和操作说明；本轮没有连接串口、进入下载模式或写入芯片。

底板把主控EN、IO0引出，但本线束不额外驱动启动脚，也不把屏幕RST接主控EN。

## 证据与验收

- 底板TX/RX/GND位置从本目录120焊盘表比对，RX与TX交叉而非同名相连。
- 实物线束要求：供电芯实际缺位；未连接电脑时，用万用表确认维护线束没有适配器VBUS→底板5V的导线；接线后确认3.3V UART电平。未执行实测。
- 官方接口依据：[Espressif ESP32-S3 Serial Connection](https://docs.espressif.com/projects/esptool/en/latest/esp32s3/esptool/serial-connection.html)。

销项范围：新增单电源维护接法的设计。原有开发板USB端口的全部组合防倒灌、LDO热性能不因这份说明自动通过。
