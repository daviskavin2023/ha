## 二、底板所有模块排母物理逐脚定义表 (收货装配唯一基准)

由于市面上各淘宝商家的外购模块（PCM5102A、CJMCU-832、雷达）引脚排列各不相同，**底板排母严禁盲插直插**！装配时请严格按下表功能核对模块丝印，必要时采用杜邦线束跳线连接：

### 2.1 核心音频模块排母脚序 (按底板 Pin 1 -> Pin N)

| 接口代号 | 排针脚位 | 底板物理信号 | 对应 ESP32-S3 管脚 | 关键装配与防呆提醒 |
|---|:---:|---|---|---|
| **`J_DAC_IN`**<br>(DAC输入 6P) | Pin 1 | **`+5V`** | 主供电 5V 总线 | **直插防呆预警**：常见紫色 PCM5102A 模块如果直插，BCK 与 LCK 时钟线可能会对调导致无声！**必须比对模块丝印**，若不一致请用杜邦线单线对接。 |
| | Pin 2 | **`GND`** | 全板公共地 | |
| | Pin 3 | **`DAC_BCK`** | **`IO7`** (时钟) | |
| | Pin 4 | **`DAC_DIN`** | **`IO16`** (音频数据) | |
| | Pin 5 | **`DAC_LCK`** | **`IO15`** (左右声道选择) | |
| | Pin 6 | **`GND`** | 接地 (使能内部PLL) | 模块 SCK 脚接地，启用 PCM5102A 内部时钟发生器。 |

## 三、实物到货后万用表通电前置约束清单 (8 项安全红线)

本板制造交付后为“裸板样品”。在各采购元器件与模块实际到手后，**上电和焊接前必须严格执行以下 8 项安全红线，严禁盲插盲通电**：

1. **【雷达严禁直插】**：必须使用 5P 杜邦线束进行功能交叉跳接（底板 IO17 接雷达 TX、底板 IO18 接雷达 RX）；
2. **【C1 滤波电容极性核实】**：
   * 电解电容本体外壳印有白色减号“-”条带的一侧为负极，对应 PCB 圆孔焊盘（GND）；
   * 较长引脚的一侧为正极，插入 PCB 方孔焊盘（+5V），严禁反接！
3. **【PJ-324M 耳机座常闭通断测试】**：
   * 不插音频线时：用万用表蜂鸣档测量 Pin 2 与 Pin 3 必须导通（常闭），Pin 4 与 Pin 5 必须导通（常闭）；Pin 2 与 Pin 4 之间绝不能导通！
   * 插入 3.5mm 音频插头后：Pin 2 与 Pin 3 必须断开，Pin 4 与 Pin 5 必须断开。
4. **【各模块实物排针正反面 1:1 核对】**：
   * 对照实际到货的紫色 PCM5102A、CJMCU-832、INMP441，逐个确认正反面丝印管脚与底板排母标号 100% 对应；功放特别注意 Pin 5 为 5V、Pin 4 为 GND，严禁插反！
5. **【屏幕背光与触控实测】**：
   * 确认屏幕转接板自带背光恒亮电路；CST816D 在小智固件中配置为 Polling 轮询模式，无需 INT 中断脚；
6. **【配套固件在开发板验证先行】**：
   * 在裸板打样焊接前，先用单独的 ESP32-S3 开发板编译运行小智官方固件，验证 Wi-Fi、音频流与串口驱动正常；
7. **【严禁双电源同时接入】**：
   * 用电脑 Type-C 数据线连接主控核心板进行固件烧录调试时，**必须拔下底板 5V 电源**；
   * 整机装配完成合盖后，仅通过外壳 Type-C 口输入 5V 2A 电源，严禁双电源同时接入。
8. **【固件音频限幅与 LDO 温升实测】**：
   * 小智固件中音频输出音量必须软限制在 -12dB ~ -6dB，防止 PAM8302A 削顶破音；整机通电工作 15 分钟后测量主控 LDO 芯片表面温升，确保在 65°C 安全阈值以内。
