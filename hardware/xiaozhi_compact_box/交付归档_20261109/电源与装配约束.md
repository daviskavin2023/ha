# 电源与装配约束（装配修订2）

主体60×92×66mm，内腔56×88×62mm，主板48×68×1.6mm。后壁螺柱3mm、主控排母8.5mm；完整模块/插头预算见装配CAD参数。喇叭预算后缘与主控预算前缘7.4mm，功放与主控2.9mm；12个打印网格闭合、零件/参考模块/螺丝头无几何相交。旧54×76×48mm图及其0.9mm名义余量已被本修订替代。

这些值以BOM/预留包络为输入，不把未测模块称为厂商完整机械图；CAD无相交不代表实际打印公差、每根线和实际天线/RF已经验证。来源与限制在装配CAD说明中明确。

## 供电和维护

闭壳只引入一条5V电源线。主控两只USB口不对外开孔，开盖维修；独立UART维护仅接3.3V TX/RX/GND，不装适配器VCC芯，线束设计和取线点已核对。开盖插主控USB仍须断外部电源；未实现任意双源并联互锁，不能据此宣传所有电源组合不会倒灌。

原C1位置留空，100µF/16V电容固定于后壳卡位，正负分接底板侧雷达5V/GND支线（J_RADAR.1/.2同网），目标≤25mm。实物极性、绝缘与导通尚需检查。

LDO输入电流约为输出电流加静态电流；5V→3.3V、0.5A时耗散约0.85W，不能折算成5V侧350mA。按实际LDO型号、ESP峰值、屏/触控、MIC负载及5V雷达/DAC/功放支路测量。5V/2A为容量建议，不是已经测得的整机峰值。

记录环境温度、各支路电流、端电压和最坏负载闭壳热平衡温度曲线，依据实际器件额定值判定，不用“15分钟表面65°C”作通用通过阈值。真实显示边界/触控、音频波形/失真、天线位置/RSSI、雷达覆盖与装配公差未实测，保留在样机记录表。
