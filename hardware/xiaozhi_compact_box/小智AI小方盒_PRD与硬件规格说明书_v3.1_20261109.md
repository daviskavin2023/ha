# 小智小方盒 PRD 与硬件规格说明书 (v3.1 嘉立创原生工程放行版)

## 一、项目概述与产品定义
* **产品名称**：小智 AI 桌面小方盒 (Xiaozhi MiniCube)
* **硬件设计环境**：**嘉立创 EDA 专业版 (EasyEDA Pro)**（工程文件：`Xiaozhi_v31_Verified_20261109.eprj2`）
* **生产加工包**：`小智小方盒_JLC单一钻孔生产包_v3.1_20261109.zip`（SHA-256: `68c086f2e09be56c96613146e4b14ce92c545df97a1d78f78e5ca86e84b474a2`）
* **产品形态**：复古桌面微型智能立方体（一体化紧凑封装，底面出声，无外露线束）。
* **核心功能**：
  1. 2.01 英寸高清全彩 IPS 触摸交互（ST7789 驱动 + CST816D 电容触控，2.5D 黑晶曲面一体玻璃无孔面板）；
  2. 智能音频双模自动硬件切换（直插 3.5mm 音箱物理切断内胆喇叭 + 拔线 R1/R2 隔离混音驱动 2840 腔体喇叭）；
  3. 24GHz 毫米波人体近场存在感应（HLK-LD2410C 人来唤醒、人走微光/休眠）；
  4. 高灵敏度数字麦克风阵列远场拾音（INMP441 I2S 全向数字麦克风）；
  5. 独立硬件供电防倒灌与大容量滤波（外置 5V Type-C 供电口 + 100µF 高频电解电容，主控 IN-OUT 彻底不焊接，调试时断开底板外置电源）。

## 三、结构尺寸与工程装配尺寸链 (方案B 100% 零干涉)

* **整机外壳公称尺寸**：宽 54.0mm × 高 76.0mm × 深 48.0mm（壁厚 2.0mm）；
* **外壳内部净空尺寸**：宽 50.0mm × 高 72.0mm × 深 44.0mm；
* **主 PCB 底板尺寸**：宽 48.0mm × 高 68.0mm（板厚 1.6mm，左右各留 1.0mm 装配旷量，上下各留 2.0mm 装配旷量，四角倒角 R3）；
* **叠层高度链**：螺柱 1.5mm + PCB 1.6mm + 排母 8.5mm + 主控厚度 3.5mm = 15.1mm；
* **底部避让净空**：44.0 - 15.1 - 28.0 = +0.9mm（名义空腔余量）。插件焊接引脚必须剪平至 <= 1.0mm。

## 四、电气架构与硬件接口规范 (嘉立创原生工程)

### 4.1 电源与地平面规范
* **5V 主供电**：外置 5V Type-C 经 `J_PWR_5V` 输入，入口处并联 100µF 高频电解电容（C1）；
* **GND 地网络**：底层已由嘉立创原生铺设大面积 GND 覆铜平面，全板地网络通过实体走线与地铜双重贯通；
* **间距规则全达标**：
  * 全板异网导体最小间距 >= 0.2017mm（通过嘉立创 0.20mm 制造门槛）；
  * 全板走线与地铜边缘到板框（含四个 R3 圆角）最小净距实测为 **0.360mm**，完全满足且高于板厂 0.30mm 板边规则；
  * 顶层丝印标题移动至中央腹地安全区，距离最近焊盘 >= 1.25mm，绝无焊盘干涉；C1 明确标出正极“+”号。

## 五、实物到货后万用表通电前置约束清单 (严禁到手盲插盲测)

在嘉立创打样裸板与淘宝各元器件到货后，必须在**上电和焊接之前，严格完成以下万用表实测核验**：

1. **PJ-324M 插座通断测试**：
   * 不插音频线时：用万用表蜂鸣档测量 Pin 2 与 Pin 3 必须导通（常闭），Pin 4 与 Pin 5 必须导通（常闭）；Pin 2 与 Pin 4 之间绝不能导通！
   * 插入 3.5mm 公头音频线后：Pin 2 与 Pin 3 必须断开，Pin 4 与 Pin 5 必须断开。
2. **各采购模块实物排针 1:1 核对**：
   * 对照实际到货的 PCM5102A 紫板、CJMCU-832 功放、INMP441 麦克风、HLK-LD2410C 雷达模块，逐个确认正反面丝印管脚与底板排母标号 100% 对应；
3. **PC 烧录与外置电源隔离规程**：
   * 用电脑 Type-C 数据线连接主控核心板进行固件烧录调试时，**必须拔下底板 5V 电源**；
   * 整机装配完成合盖后，仅通过外壳 Type-C 口输入 5V 2A 电源，严禁双电源同时接入。
