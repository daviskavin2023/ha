## 五、实物到货后万用表通电前置约束清单 (8 项安全红线)

本板打样交付后仅为“裸板样品”。在各采购元器件与模块实际到手后，**上电和焊接前必须严格执行以下 8 项安全红线，严禁盲插盲通电**：

1. **【雷达严禁直插】必须使用交叉线束连接**：
   * HLK-LD2410C 模组**绝对不能直接插在底板 J_RADAR 排母上**！
   * 直插会导致底板 TX 对应雷达 TX、底板 RX 对应雷达 RX，串口通信完全反向失效！
   * **正确连接方式**：必须使用 5P 杜邦线束交叉跨接：
     * 底板 Pin 1 (5V) -> 雷达 VCC
     * 底板 Pin 2 (GND) -> 雷达 GND
     * 底板 Pin 3 (IO8) -> 雷达 OUT
     * 底板 Pin 4 (底板TX/ESP_RX IO17) -> **接雷达 TX**
     * 底板 Pin 5 (底板RX/ESP_TX IO18) -> **接雷达 RX**
2. **【C1 电解电容极性核对】**：
   * 电容本体外壳印有白色减号“-”条带的一侧为负极，对应 PCB 圆孔焊盘（GND）；
   * 较长引脚的一侧为正极，插入 PCB 方孔焊盘（+5V），严禁反接！
3. **【PJ-324M 插座通断测试】**：
   * 不插音频线时：用万用表蜂鸣档测量 Pin 2 与 Pin 3 必须导通（常闭），Pin 4 与 Pin 5 必须导通（常闭）；Pin 2 与 Pin 4 之间绝不能导通！
   * 插入 3.5mm 音频插头后：Pin 2 与 Pin 3 必须断开，Pin 4 与 Pin 5 必须断开。
4. **【各模块实物排针正反面 1:1 核对】**：
   * 对照实际到货的紫色 PCM5102A、CJMCU-832、INMP441，逐个确认正反面丝印管脚与底板排母标号 100% 对应；
5. **【屏幕背光与触控实测】**：
   * 屏幕供电为 3.3V，到货后确认转接板自带背光恒亮电路；CST816D 在小智固件中配置为 Polling 轮询模式，无需 INT 中断脚；
6. **【配套固件在开发板验证先行】**：
   * 在裸板打样焊接前，先用单独的 ESP32-S3 开发板编译运行小智官方固件，验证 Wi-Fi、音频流与串口驱动正常；
7. **【严禁双电源同时接入】**：
   * 用电脑 Type-C 数据线连接主控核心板进行固件烧录调试时，**必须拔下底板 5V 电源**；
   * 整机装配完成合盖后，仅通过外壳 Type-C 口输入 5V 2A 电源，严禁双电源同时接入。
8. **【固件音频限幅与 LDO 温升实测】**：
   * 小智固件中音频输出音量必须软限制在 -12dB ~ -6dB，防止 PAM8302A 削顶破音；整机通电工作 15 分钟后测量主控 LDO 芯片表面温升，确保在 65°C 安全阈值以内。
