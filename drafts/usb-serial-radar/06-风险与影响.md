# 风险与影响

| 项 | 影响 |
|---|---|
| **3051 中控进程/物理屏** | **不改、不停**；中控只读 HA。除非有人把面板实体改绑到 USB 传感器，否则无感 |
| **其它 PVE VM** | 仅给 138 加 USB；不碰其它 VM/容器 |
| **小智语音功能** | **重刷后丢失**（麦/喇叭/voice_assistant/提示音）直至刷回原 ESPHome 备份 |
| **原 ESPHome Wi-Fi 集成** | 本已因 Wi-Fi 损坏不可用；刷后仍无 Wi-Fi |
| **LD2410 BLE（63F5）** | 模块仍可 BLE 广播；与 USB 方案并行。自动 reload 自动化继续只服务 BLE |
| **刷写风险** | 备份失败勿刷；新固件必须四件套偏移（禁 `firmware.bin@0x0`）；回滚用整片备份 `@0x0`；CH343 DTR 可能复位——HA 侧必须 `dsrdtr: false` |
| **双 Type-C** | 原生 USB 口狂抖时拔掉；只用 CH343。禁止 USB+底板 5V 同时供电 |
| **引脚** | 必须按客厅 yaml（17/18），不要按小智 v3 台账反接表 |

## 验收（上线后）
1. 宿主或 HA 每秒见到合法 JSON。  
2. template 实体随走动变化。  
3. `ha_watch_ld2410_ble_*` 仍 on；其它自动化数量不异常。  
4. 3051 面板照常。
