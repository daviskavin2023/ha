# D. HA 配置步骤与共存

## 备份
```bash
ssh -p 22222 root@10.10.10.38 \
  'cp /mnt/data/supervisor/homeassistant/configuration.yaml \
      /mnt/data/supervisor/homeassistant/configuration.yaml.bak.$(date +%Y%m%d-%H%M%S)'
```
拷一份到 `3038/backups/`。

## 校验与生效
```bash
ha core check          # 必须通过
ha core restart        # serial 平台改 configuration.yaml 需要重启 core（非 automation.reload）
```
回滚：恢复 bak → `ha core check` → `ha core restart`。

## 与现网关系
| 组件 | 关系 |
|---|---|
| `ld2410_ble`（`HLK-LD2410_63F5`） | 可并存；实体名不同（USB 用「客厅USB雷达*」） |
| `ha_watch_ld2410_ble_offline_reload_20261110` | 只 reload BLE 条目，**不**动 USB serial |
| 原 ESPHome `ld2410-test` 集成 | Wi-Fi 坏已无意义；重刷后可考虑禁用该 config entry（另授权） |
| 客厅灯自动化 | **不要**接本 USB 实体，除非新 PRD |
| 3051 中控 | 不改；仅当有人改面板绑定实体时才会读到新传感器 |

## 风险提示（HA 2026.5 serial 回归）
当前 core **2026.9.2**；若升级到曾出问题的版本，串口拔出可能导致 core 挂起。务必 `dsrdtr: false`。
