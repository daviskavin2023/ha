## UART / 引脚（以 3038 yaml + 客厅 PRD 为准）
| 信号 | ESP32-S3 | 说明 |
|---|---|---|
| ESP `uart` tx_pin | **GPIO17** | → 雷达 RX |
| ESP `uart` rx_pin | **GPIO18** | ← 雷达 TX |
| 波特率 | **256000** 8N1 | LD2410 工程帧 |
| Logger / USB 串口 | **UART0**（`hardware_uart: UART0`） | 经板上 **CH343** Type-C 出到主机 |

> 注：小智 v3 PCB 台账曾写「雷达 TX→GPIO17」，与本客厅板 3038 接线**相反**。重刷必须以 **GPIO17=ESP TX、GPIO18=ESP RX**（本 yaml）为准。

## 板上其它外设（重刷会丢掉的能力）
来自 `ld2410-radar.yaml`：
- Wi-Fi + ESPHome API/OTA
- I2S 麦克风（GPIO4/5/6）+ 喇叭（GPIO7/15/16）
- `voice_assistant` / `Xiaozhi Speaker` / 开机 RTTTL 提示音
- LD2410 的 number/button 调参实体

**所属项目**：硬件/语音链路偏 **小智（3051 相关）**；HA 侧登记在 **3038**。  
**3051 中控**：读 HA WebSocket，不直连此串口；本方案不改 3051 服务。但重刷后小智语音板功能会没，直到另刷回语音固件。

## 与现网 BLE 雷达关系
- `ld2410_ble` / `HLK-LD2410_63F5`：同一颗雷达的 **BLE 通道**（经客卫蓝牙代理）。
- USB 串口方案：同一颗雷达的 **UART 工程数据**（经 ESP 转发）。
- 可并存观察；自动化勿同时用两套冲突逻辑。已上线的 `ha_watch_ld2410_ble_offline_reload_20261110` 只影响 BLE 集成。
