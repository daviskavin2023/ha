# 客厅雷达板 USB 串口进 HA — 待审方案（不执行）

状态：**仅草稿**。不刷写、不改 VM、不改 HA，除非另行「上线」授权。

## 目标
ESP32-S3（Wi-Fi 坏）经 **CH343** USB 串口，每秒输出一行 LD2410 JSON → PVE 直通 → HA `serial` 传感器 + template 解析。

## 推荐路线（最安全）
1. **在 PVE 宿主用 Docker 跑 esptool** 做整片备份 + 刷写（不污染宿主 Python；不占用 HA）。
2. 刷写成功并确认串口 JSON 稳定后，再 **USB 直通给 VM 138**。
3. HA 用 YAML `sensor: - platform: serial`（官方仍支持；改 configuration.yaml 后需 **重启 HA core**，`automation.reload` 不够）。

不推荐一开始就把口直通进 HA 再刷：HAOS 刷写工具链弱，且 2026.5 附近 serial 有过挂死 bug（2026.6 起恢复；当前 HA **2026.9.2** 一般可用，但仍建议 `dsrdtr: false`）。

## 步骤顺序
A. 备份现固件（Docker esptool + CH343，整片 16MB）  
B. 编译并刷入最简 Arduino/PlatformIO 固件（关 Wi-Fi/BT；bootloader@0x0 + partitions@0x8000 + boot_app0@0xe000 + firmware@0x10000）  
C. 宿主 `timeout`/`cat` 或 `python -m serial.tools.miniterm` 确认 JSON  
D. 备份 `138.conf` → `qm set` USB 直通 → HA 内出现 by-id  
E. 备份 `configuration.yaml` → 追加 serial/template → `ha core check` → **重启 core**  
F. 观察与 `ld2410_ble` 并存，不接灯联动

## 用户需要做的物理操作
- 保持 **CH343 那只 Type-C** 插在 PVE（现 `1-9`）；原生 `303a:1001` 口可拔掉以免狂抖干扰。
- 刷写时：CH343 一般 **自动 DTR/RTS 进下载模式**；若失败再按板 **BOOT**（按住 BOOT 点 RST，或按芯片丝印）。
- 刷写/备份时 **拔掉底板外置 5V**（客厅/小智 PRD 铁规：电脑 USB 调试时禁止双供电）。
- 合盖长期供电只用外壳 5V；USB 只给串口/供电其一，避免双电源。

## 回滚要点
- 固件：整片备份 `write_flash … 0x0 fullflash-*.bin` 写回（见 02）；新固件用四件套偏移，禁止 `firmware.bin@0x0`  
- VM：恢复 `138.conf` 备份并 `qm set` 删 usb 或恢复文件后热/冷生效  
- HA：恢复 `configuration.yaml` 备份并重启 core  
详见各分册。
