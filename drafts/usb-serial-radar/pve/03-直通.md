# C. PVE USB 直通 → HA VM 138

**时机**：固件已在宿主验证 JSON 稳定之后。若还要在宿主刷写，**先刷再直通**。

## 备份 VM 配置
```bash
# PVE
cp -a /etc/pve/qemu-server/138.conf \
  /etc/pve/qemu-server/138.conf.bak.$(date +%Y%m%d-%H%M%S)
# 同时拷到 3038/backups/
qm config 138 | tee /root/backups/qm-138.conf.$(date +%Y%m%d-%H%M%S).txt
```

## 添加直通（推荐按 vendor:product）
```bash
# 查看空闲 usb 槽
qm config 138 | grep -i usb || true
# 假设用 usb0
qm set 138 -usb0 host=1a86:55d3,usb3=0
```
或按口（更钉死物理口，换线可能变）：
```bash
# lsusb -t 确认 Bus 1 Port 9 → 主机控制器地址因机器而异，优先 vendor:product
qm set 138 -usb0 host=1-9
```

## 是否可热插
- Proxmox `qm set ... -usbN host=...` 对**正在运行**的 VM 通常可热添加 USB。
- 若 HA 内看不到设备：在 HA 里 `ha hardware info`；仍无则 **重启 VM 138**（需另授权；本草稿不执行）。
- 回滚：
```bash
qm set 138 -delete usb0
# 或
cp /etc/pve/qemu-server/138.conf.bak.XXXX /etc/pve/qemu-server/138.conf
# 视情况 qm reboot 138（需授权）
```

## HA 内确认
```bash
ssh -p 22222 root@10.10.10.38 'ha hardware info' | grep -iE '1a86|55d3|ttyACM|by-id'
ls /dev/serial/by-id/   # 在 HAOS 内
```
记下稳定路径，形如：  
`/dev/serial/by-id/usb-1a86_USB_Single_Serial_5D33083851-if00`
