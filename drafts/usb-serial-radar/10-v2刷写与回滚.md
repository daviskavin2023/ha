## 刷写：先把串口从 HA 手里放出来（三选一）
现在 CH343 直通在 VM 138（`qm set 138 -usb0 host=1a86:55d3`）。HA 的 serial 传感器一直占着口，刷写工具和 HA 同时读会刷失败，所以必须先放口。

### 方案 A（推荐，不动直通、不重启 VM，未实操）
在 HAOS 宿主（`ssh -p 22222 root@10.10.10.38`）里用一次性容器跑 esptool：
```bash
# 1) HA 照常运行时先准备好镜像和 esptool（避免停 core 时等下载）
docker run --name esptool-prep python:3.12-slim pip -q install esptool==4.8.1 && \
  docker commit esptool-prep local/esptool:4.8.1 && docker rm esptool-prep
# 2) 把 firmware.bin 放到 /mnt/data/supervisor/share/ld2410-v2/（HA 的 /share），核对 sha256
# 3) 停 HA core（全部自动化停 1–3 分钟）
ha core stop
docker run --rm --device=/dev/ttyACM0 -v /mnt/data/supervisor/share/ld2410-v2:/img local/esptool:4.8.1 \
  esptool.py --chip esp32s3 -p /dev/ttyACM0 -b 460800 write_flash 0x10000 /img/firmware.bin
ha core start
```
`/dev/ttyACM0` 以 HAOS 内 `ls -l /dev/serial/by-id/` 指向为准。停摆就是 core 停的这 1–3 分钟，期间所有自动化都不跑，包括阳台灯和客厅灯。

### 方案 B（用过的工具链，但可能要重启 VM）
```bash
# PVE
cp -a /etc/pve/qemu-server/138.conf /etc/pve/qemu-server/138.conf.bak.$(date +%Y%m%d-%H%M%S)
qm set 138 -delete usb0          # 热拔，口回到 PVE /dev/ttyACM0
/root/venvs/esptool/bin/esptool.py --chip esp32s3 -p /dev/ttyACM0 -b 460800 write_flash 0x10000 firmware.bin
qm set 138 -usb0 host=1a86:55d3  # 热插回去
```
上次热插后 HA 看不到设备，最后用了 `qm reset 138`。如果这次也一样，整个 HA VM 要重启，停摆好几分钟。HA serial 掉口时最好先停 core 或接受日志报错。

### 方案 C（物理）
把 CH343 线临时插到 Mac 刷（Mac 需 `pip install esptool` 到 venv），再插回 PVE 原口 `1-9`。直通是按 vendor:product 配的，一般能自动重连，但没验证过。

## 刷写后验收
1. 30 秒内 `sensor.ld2410_usb_json` 恢复每秒更新，8 个字段正常。
2. 开机 3 秒后应陆续出现带 `cfg`、`ms`、`ss` 的 3 行。在 HA 开发者工具看 `sensor.ld2410_usb_json` 属性，或用 `/api/history` 查最近 1 分钟。
3. `cfg.ok=true` 时，记录 `mg/sg/idle/ms/ss/fw` 到 07-上线记录。`ok=false` 时，上报照常可用，再查 TX 线。
4. 融合实体 `binary_sensor.ke_ting_shuang_lei_da_you_ren` 可用；阳台自动化的 `radar_ok` 恢复 true。
5. 修改参数先不做，读出来以后另定。

## 回滚
- **回到 v1（首选）**：同样的放口方式，`write_flash 0x10000 pio-upload-dio/firmware.bin`（sha256 `c9d2b51f…`）。
- **回到原 ESPHome（最后手段）**：整片备份 `fullflash-20261110-012256.bin`（sha256 `b5f0f88a…`，见 `08-备份sha256.md`），用 `write_flash --flash_mode keep --flash_freq keep --flash_size keep 0x0 …`。注意：这会回到 Wi-Fi 版 ESPHome（Wi-Fi 已坏），**USB JSON 会消失**，HA 的 USB 雷达全部失效，阳台灯走旧条件。
- 方案 B 的直通回滚：`cp 138.conf.bak.* 138.conf` 或重新 `qm set 138 -usb0 host=1a86:55d3`。
