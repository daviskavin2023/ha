## 数据约定与更新

`id` 是稳定编号，新增设备使用新编号；改名、移动时保留旧编号并记录新证据。`room_id`引用房间表。`position_px`使用1888×1334归一化原图坐标，左上原点、向右为东、向下为南；不是毫米或米。`metric_transform=null`表示未完成尺寸标定。`position_status=approximate`是可供复核的示意点，`room_located`是只知房间与照片相对位置，`unlocated`是尚未定位。`diagram_label_anchor_px`仅用于绘图排版，不可作为安装坐标或距离计算依据。安装高度、朝向、探测覆盖未实测时保持null；不得推断空值代表无人、无设备或零覆盖。

后续更新顺序：

1. 核对S04/S05/S06/S13的墙面方位与平面位置，再填回坐标；已撤回的旧点不能继续使用。
2. 补充S08-S12及D01安装点；确认LD2410是否已安装及具体位置。
3. 补充其他房间灯具位置、数量、每个开关实际控制的回路。
4. 只读核对HA设备/实体/区域注册表，绑定实物与实体并记录核对日期；失效候选不得直接调用。
5. 如需分析雷达覆盖，再实测高度、方向、距离、遮挡、窗帘与风扇位置，记录测量条件；不改硬件参数。

这是设计和分析资料，HA不会自动读取此JSON；以后接入平面图卡片或定制仪表盘时可复用坐标和实体映射。控制规则的任何调整另行按项目约束处理，不能仅凭地图跨区加入触发源。离家/回家必须保持物理触发；不得测试触发空调；服务器/投影仪插座与家庭中控资产保护规则继续有效。
